# Roblox Character Animation System

A Roblox character animation system featuring Blender-created locomotion and weapon animations with sprinting and configurable attack behavior.

## Demo

https://github.com/user-attachments/assets/1e9f4f96-3ee4-4b0c-b60f-ac4c3d8f789d

## Features

- Custom idle, walking, running, and attack animations created in Blender
- Dynamic switching between idle, walking, and running animations
- Sprinting with adjusted movement and animation speed
- Weapon attack animation triggered by player input
- Adjustable attack animation speed
- Optional movement locking during attacks

## Built With

- Luau
- Roblox Studio
- Blender
